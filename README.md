# Virtual Gyrocompassing for FOG & MEMS Sensors

## 📌 About the Project
This repository contains the ongoing research and development code for my Master's thesis in Autonomous Vehicle Engineering. The project focuses on developing and optimizing virtual gyrocompassing algorithms to enhance the accuracy of autonomous navigation systems using Fiber Optic Gyroscopes (FOG) and MEMS sensors.

## 🚧 Current Status: Work in Progress
This project is currently under active development. The algorithms are being tested and refined. Final results and comprehensive documentation will be added upon the completion of the thesis.

## 🛠️ Tech Stack & Tools
*   **Languages:** MATLAB 
*   **Simulation & Modeling:** Simulink
*   **Sensors Analyzed:** FOG (Fiber Optic Gyroscope), IMU/MEMS

## 🧠 Key Features (So far)
*   Data filtering and noise reduction from raw sensor outputs.
*   Implementation of a Kalman Filter for accurate heading estimation.
*   Mathematical modeling of sensor drift and bias.
